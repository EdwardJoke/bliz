# Frontend design

## When to use
- The user asks for a new page, section, or component.
- Existing UI looks generic and needs a design pass.

## How it works
1. Establish a type scale and a spacing rhythm before writing markup.
2. Pick one accent colour and use it sparingly.
3. Verify contrast, focus states, and reduced-motion behaviour.
